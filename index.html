database System Architecture, DB Setup & Admin Account Creation

1. Technology Stack & Relational Database Design (`EnrollaDB`)

This application runs in a unified single-file architecture using HTML5, CSS3, ES6+ JavaScript, and a transactional relational store persisted in localStorage under key enrolla_relational_db_v3.

  • programs (PK: code) → One-to-Many with students and Many-to-Many with subjects via subjectCodes[].
  • students (PK: studentId, FK: programCode) → Stores student records and enrollment status.
  • subjects (PK: code, FK: programCode) → Stores maxCapacity, live enrolledCount, and auto-computed Available / Full status.
  • enrollments (PK: id, FK: studentId, FK: subjectCode) → Junction table enforcing zero duplicate enrollments and strict capacity ceilings.
  • settings & auditLogs → Controls the enrollment window (Open, Scheduled, Closed, Deadline Passed) and logs all admin operations.
